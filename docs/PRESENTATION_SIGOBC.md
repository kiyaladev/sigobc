# SIGOBC - Système Informatique de Gestion des Opérations Budgétaires des Collectivités

---

## 📋 Présentation Générale

**SIGOBC** est une application informatique moderne conçue pour simplifier et automatiser la gestion budgétaire des collectivités territoriales (mairies, communes, régions).

Cette solution permet de gérer l'ensemble du cycle budgétaire : des prévisions aux exécutions, en passant par les mandats et bordereaux.

---

## 🎯 Objectifs du Logiciel

| Objectif          | Description                                                |
| ----------------- | ---------------------------------------------------------- |
| **Modernisation** | Remplacer les processus manuels par une solution numérique |
| **Efficacité**    | Réduire le temps de traitement des opérations budgétaires  |
| **Traçabilité**   | Assurer un suivi complet de toutes les transactions        |
| **Transparence**  | Faciliter le contrôle et l'audit des finances publiques    |
| **Conformité**    | Respecter les normes de gestion des finances publiques     |

---

## 🔧 Fonctionnalités Principales

### 📊 Module Gestion des Dépenses

| Fonctionnalité             | Description                                                |
| -------------------------- | ---------------------------------------------------------- |
| **Tableau de Bord**        | Vue d'ensemble des dépenses avec indicateurs clés          |
| **Natures de Dépense**     | Gestion des catégories de dépenses (chapitres budgétaires) |
| **Comptes Fonctionnels**   | Organisation détaillée par sous-chapitres                  |
| **Prévisions Budgétaires** | Planification et suivi des crédits alloués                 |
| **Mandats de Dépense**     | Création et gestion des ordres de paiement                 |
| **Bordereaux de Mandats**  | Regroupement des mandats pour transmission au trésor       |
| **Statistiques**           | Analyses graphiques et rapports détaillés                  |

### 💰 Module Gestion des Recettes

| Fonctionnalité               | Description                                       |
| ---------------------------- | ------------------------------------------------- |
| **Tableau de Bord**          | Vue synthétique des recettes perçues et attendues |
| **Déclarations de Recettes** | Enregistrement des entrées financières            |
| **Taxes et Impôts**          | Gestion des différentes sources de revenus        |
| **Mandats de Recette**       | Ordres de recouvrement                            |
| **Bordereaux de Recettes**   | Récapitulatifs pour le trésor public              |
| **Prévisions de Recettes**   | Estimation des revenus attendus                   |
| **Statistiques**             | Suivi de la performance des recouvrements         |

### 👥 Module Administration

| Fonctionnalité               | Description                             |
| ---------------------------- | --------------------------------------- |
| **Gestion des Utilisateurs** | Création et gestion des comptes         |
| **Contrôle d'Accès**         | Attribution des droits par rôle         |
| **Statistiques Globales**    | Vue consolidée de toutes les opérations |
